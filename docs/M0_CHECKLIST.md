# M0 — Feasibility Checklist

**ห้ามเริ่ม M1 ก่อน M0 ผ่านครบ** — ประหยัดเวลา/เงินตั้งแต่ยังไม่ลงทุน

## 1. Shopee Live PC + Stream Key

- [ ] เข้า Shopee Seller Centre ด้วยบัญชีไทย
- [ ] เข้า Live Streaming → เลือก Stream from PC/Studio
- [ ] ได้ **RTMP URL + Stream Key** หรือไม่
- [ ] ถ้าไม่มี → บัญชีขายเองต่างหากที่ยังมีสิทธิ์ไหม? หรือต้องขอเพิ่มสิทธิ์
- [ ] ยืนยันบนเวอร์ชัน Shopee Live ล่าสุด (บางฟีเจอร์มีแค่บางภูมิภาค)

**ถ้าไม่มี Stream Key** → ระบบจะไม่มีทางออกที่ถูกต้องตามเงื่อนไข **หยุด**

## 2. นโยบาย AI host + ค่าคอม (ติดต่อ Shopee ไทย)

- [ ] ส่งอีเมล / ติดต่อ Account Manager Shopee ถามตรง:
  - AI digital human host ติดป้าย AI แล้วใช้งานได้ปกติไหม
  - ค่าคอม affiliate ยังจ่ายไหม
  - ข้อจำกัดอื่น (เช่น ห้ามใช้บัญชีเดียวหลาย AI host, ชั่วโมงไลฟ์ขั้นต่ำ)
- [ ] บันทึกคำตอบเป็นลายลักษณ์อักษร / เมล

**ถ้าค่าคอมถูกตัด** → โมเดลรายได้อาจไม่คุ้ม → re-plan

- [ ] ตรวจว่าใช้ voice clone เชิงพาณิชย์ได้ไหม

### Voice sample / วิดีโอฐาน
- [ ] หนังสือยินยอมจากบุคคล (ครอบคลุม commercial use, ระยะเวลา, การถอน)

## 4. GPU + ค่าใช้จ่าย

- [ ] วัดราคา RTX 3080Ti/4090 มือสอง vs เช่า cloud (RunPod/vast.ai) + latency
- [ ] ประมาณชั่วโมงไลฟ์/วัน × ต้นทุน GPU = ต้นทุนต่อชั่วโมง
- [ ] ต้นทุน TTS (ถ้าใช้ cloud TTS)
- [ ] ต้นทุน Claude API ต่อสคริปต์ 1 ชั่วโมง (ประมาณ)

## 5. ประเด็นกฎหมาย/นโยบายอื่น

- [ ] กฎหมายไทยเรื่อง deepfake / voice clone (ตรวจพ.ร.บ. ล่าสุด)
- [ ] การแสดงราคา/โปรโมชันถูกต้องตามกฎหมายคุ้มครองผู้บริโภค
- [ ] ติดป้าย "AI" ชัดเจนบนจอตลอดเวลา (รองรับทั้งกฎไทยและ Shopee Video)

## เกณฑ์ผ่าน M0

- Shopee Live PC + Stream Key ใช้ได้ ✓
- Shopee ไทยยืนยันลายลักษณ์อักษรว่าใช้ AI host + รับค่าคอมได้ ✓
- License ทุกตัวในสาย production ใช้เชิงพาณิชย์ได้ (หรือมีแผน B) ✓
- ต้นทุนต่อชั่วโมงไลฟ์ ≤ รายได้คาดการณ์ ✓
- หนังสือยินยอมพร้อม ✓

**ครบทั้ง 5 ข้อค่อยเริ่ม M1**
