# POLICY — ข้อกฎและข้อปฏิบัติ

> อ่านประกอบ `CONTEXT.md §5` และ `M0_CHECKLIST.md`

## 1. ป้าย AI-generated

Shopee Video Content Guidelines (SG, มีผล 1 ส.ค. 2026): วิดีโอ AI-generated/digital human ต้องเปิด toggle "AI content" ก่อนโพสต์
- https://help.shopee.sg/portal/10/article/201777

**สิ่งที่ระบบต้องทำ:**
- [ ] แสดง overlay คำว่า "AI" บนจอตลอดไลฟ์ (บน OBS)
- [ ] เปิด toggle AI content ตอนเริ่มไลฟ์
- [ ] บันทึก log ว่าเปิดจริง (screenshot/API log)

## 2. ความถูกต้องของเนื้อหา

- [ ] สคริปต์ที่ LLM แต่ง **ห้ามอ้างสรรพคุณเกินจริง** โดยเฉพาะอาหาร/ยา/เครื่องสำอาง (อย.)
- [ ] ราคา/โปรโมชัน/สต็อก ต้องตรงกับหน้าสินค้าในเว็บจริง
- [ ] กำหนด prompt system ของ `script_engine.py` ให้ปฏิเสธคำโฆษณาเกินจริง (ดูในโค้ด)

## 3. ไม่ใช้วิดีโออัดวนในที่ที่ห้าม

- VN: Shopee ระบุชัดว่าเล่นวิดีโออัดไว้ซ้ำ = ละเมิดระดับกลาง
- TH: ยังไม่ยืนยัน แต่ควรออกแบบให้ **ไม่วนวิดีโอเดิม**:
  - ใช้ idle action หลายคลิป สุ่มสลับ
  - ตอบสนองคอมเมนต์ (M5)
  - แทรกข้อความจากผู้ควบคุมได้ทันที

## 4. ไม่ bypass กล้องจริง

**ห้าม:**
- Virtual camera บนมือถือ root เพื่อหลอกแอปไลฟ์
- Reverse engineer API Shopee ปักตะกร้าอัตโนมัติ

**ให้ใช้ช่องทางที่แพลตฟอร์มอนุญาต:**
- Shopee Live PC + Stream Key + OBS
- ปักสินค้าโดยคนกดเอง (ระบบขึ้น cue ให้)

## 5. ความยินยอมของบุคคล

- หนังสือยินยอมใช้ภาพ+เสียงเชิงพาณิชย์
- ระบุ: ขอบเขตการใช้, ระยะเวลา, สิทธิ์ถอน, ค่าตอบแทน
- เก็บต้นฉบับ + สแกน

## 6. ข้อมูลผู้ชม (ถ้าจะทำ M5)

- ถ้าอ่านชื่อ/ข้อความคนในคอมเมนต์ออกจากปาก AI → PDPA ต้องรองรับ
- Opt-out: ให้มีคำสั่ง "อย่าอ่านชื่อ" (เช่น พิมพ์ `!noname` ในคอม)
- ไม่เก็บ log ข้อความส่วนตัวเกินจำเป็น

## 7. ความปลอดภัยข้อมูล

- `ANTHROPIC_API_KEY`, Stream Key, voice sample เก็บใน `config/config.yaml` ที่ `.gitignore`
- ห้าม commit สินทรัพย์เสียง/ภาพของบุคคลเข้า repo สาธารณะ

## Checklist ก่อนไลฟ์แต่ละครั้ง

- [ ] ป้าย AI อยู่บนจอ
- [ ] toggle AI content เปิดในหน้าตั้งค่าไลฟ์
- [ ] สคริปต์ตรวจแล้ว ไม่มีคำโฆษณาเกินจริง / ข้อมูลผิด
- [ ] ราคาตรงหน้าเว็บ
- [ ] คลิปวิดีโอฐาน + voice clone ยังอยู่ในสิทธิ์ที่ยินยอม
- [ ] Stream Key ไม่หลุด (ไม่ screenshot แชร์)
